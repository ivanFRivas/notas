Authentication agent (Polkit), ¿Qué es? Es el servicio que muestra el diálogo pidiendo tu contraseña cuando una aplicación necesita permisos elevados (instalar paquetes desde una GUI, cambiar configuración de red, montar discos, etc.). Sin él, esas acciones simplemente fallan en silencio o se quedan colgadas esperando una ventana que nunca aparece.,
